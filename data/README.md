# Caregiver AI Lab - Synthetic Dataset
All examples in `synthetic_examples.jsonl` are **synthetic and fictional**, generated for engineering practice only.
They do NOT represent real caregivers, patients, or clinical populations, and must not be used as clinical evidence.

## Format
JSONL, one object per line:
- example_id: EG-SYN-NNNN
- language_type: ar | mix | en (Egyptian Arabic, Arabic+English mix, English)
- input_note: the fictional daily care note
- expected_facts, important_details, uncertainties, known_contradictions, expected_summary, expected_evidence_quotes: reference annotations

## Purpose
Practice dataset for evaluating summarization models on Egyptian Arabic and mixed-language care notes — fact preservation, uncertainty handling, contradiction detection, and unsupported-claim detection.

Generated by: src/dataset.py (deterministic, seed 42, ~150 examples).
